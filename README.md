# 📚 «СловоВместе» (Lexicon Duo)
### Приложение для совместного расширения активного словарного запаса родного языка
*Создано специально для iPhone, iPad и Mac в дизайне Apple iOS 18*

---

## 🌟 Возможности приложения

### 1. 🗂️ Карточки и интервальное повторение (Spaced Repetition)
- **3D-переворот карточки** по тапу или клику.
- Полная карточка слова: ударение, часть речи, точное определение, стилистические нюансы, цитата классика (Чехов, Набоков, Достоевский), пример из живой речи и совет по применению в разговоре.
- **Озвучивание произношения** на русском языке через встроенный синтезатор речи.
- Оценка по методике интервального повторения: *Снова*, *Трудно*, *Помню*, *В активе!*

### 2. ⚔️ Дуэли подруг в реальном времени
- **Режим 1: Онлайн по коду комнаты**:
  - Создайте комнату в один клик и получите 4-значный код (например, `ABCD`).
  - Подруга вводит код на своём iPhone или iPad — вы мгновенно связываетесь напрямую через WebRTC (бесплатно, без серверов).
  - 5 синхронных раундов, живой счёт очков, быстрые эмодзи-реакции и экран триумфа с конфетти!
- **Режим 2: Дуэль на одном устройстве (За одним столом)**:
  - Идеально для посиделок в кафе или дома с iPad/iPhone — по очереди отвечайте на раунды на одном экране!

### 3. 🎯 Тренажёр и мини-игры
- **⚡ Блиц-микс (10 раундов)**: быстрый динамичный тест.
- **🎭 Подбор синонимов**: развитие ассоциативного мышления и богатства синонимического ряда.
- **🕵️ Найди самозванца**: определение лишнего слова среди группы синонимов.
- **📜 Цитаты классиков с пропусками**: проверка чувства контекста и стиля.

### 4. ✨ Истории & Челленджи для двоих
- **🔥 Челлендж дня**: совместное ежедневное задание — внедрить редкое выразительное слово в общение друг с другом или в повседневный диалог.
- **✍️ Генератор контекстных историй**: выбирает изученные слова и вплетает их в атмосферную мини-сценку, наглядно показывая, как слова звучат в живой речи.
- **Огонёк совместной практики**: ежедневный стрик дней подряд.

### 5. 📚 Совместный словарь (Лексикон)
- Поиск и фильтрация по темам: *Литературные жемчужины, Чувства и мышление, Риторика и спор, Выразительные действия, Эстетика и стиль*.
- Возможность добавлять свои слова через кнопку **«＋»** в шапке.

## 🚀 Как запустить на Mac прямо сейчас

В терминале перейдите в папку проекта и запустите:
```bash
./start.sh
```
Или вручную:
```bash
python3 -m http.server 3000
```
Затем откройте в Safari или любом браузере: **http://localhost:3000**

## 📱 Как установить на iPhone и iPad подруги (Бесплатно и за 1 минуту)

Чтобы вы и подруга могли запускать приложение с домашнего экрана как настоящую нативную иконку:

1. **Загрузите проект на бесплатный хостинг**:
   - **Вариант А (Vercel)**: перетащите папку проекта на [vercel.com](https://vercel.com) (или подключите через GitHub). Вы получите красивую ссылку вида `https://slovo-together.vercel.app`.
   - **Вариант Б (GitHub Pages)**: опубликуйте репозиторий на GitHub и включите *Settings → Pages*.
2. **Откройте ссылку на iPhone / iPad в Safari**.
3. Нажмите кнопку **«Поделиться»** (иконка квадратика со стрелкой вверх внизу экрана Safari).
4. Прокрутите вниз и выберите **«На экран Домой»** (Add to Home Screen).
5. Нажмите **«Добавить»**.

Готово! На рабочем столе появится стильная фирменная иконка «СловоВместе». Приложение будет открываться на весь экран без рамок браузера, поддерживать свайпы, звуки, тактильный отклик и работать даже без интернета!
